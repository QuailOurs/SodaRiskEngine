# Soda Console

Soda 的规则配置与引擎调试控制台，提供业务方、场景、策略、规则、工具、字段、
统计特征和参数补全等页面。

```bash
npm ci --legacy-peer-deps
npm run dev
```

控制台默认运行在 `http://localhost:8888`，API 地址配置位于 `src/config/index.js`。

本目录包含来自 iView Admin 的 MIT 许可内容，对应声明保留在 `LICENSE`。
